
# EcoSort AI

Ứng dụng hỗ trợ nhận diện và phân loại rác bằng MobileNetV2.

## Chức năng
- Tải ảnh hoặc chụp ảnh.
- Dự đoán 3 nhóm rác.
- Hiển thị điểm dự đoán.
- Cung cấp hướng dẫn xử lý tham khảo.

## Công nghệ
- TensorFlow 2.21
- MobileNetV2
- Streamlit

## Chạy ứng dụng
Cài các thư viện trong requirements.txt và chạy:

streamlit run app.py

Lưu ý: Đây là mô hình thử nghiệm, kết quả AI
không thay thế việc kiểm tra và phân loại thực tế.
